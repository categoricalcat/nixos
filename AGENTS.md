# Agent Instructions

Keep agent guidance portable: the canonical sources are plain Markdown, and tool-specific copies are generated by `users/home/ai-policies.nix`. Edit the canonical sources rather than generated files in agent configuration directories.

## Always-on project rules

- Before any repository work, read and follow [the etiquette rules](modules/services/ai/policies/etiquette/body.md).
- Whenever reading, writing, or reviewing code, read and follow [the code-quality rules](modules/services/ai/policies/code-quality/body.md).

## Task-specific skills

`policies` in `users/home/ai-policies.nix` is the skill index: each entry's `description` states when to read `modules/services/ai/policies/<name>/body.md`. Follow a skill's `references/` links only when its routing says the task needs them.

## Policy conventions

- Each policy is a folder `modules/services/ai/policies/<name>/` holding `body.md` and, when needed, `references/`. Nix adds the frontmatter.
- Skills are self-contained: they link only to the always-on rules (`ruleRefs`), never to other skills.
- Skills never restate the rules they link; they add only domain-specific guidance.

Rules state constraints; skills provide task-specific workflows and on-demand references. Do not assume that merely linking a document loads it—read the linked file when its stated condition applies.
